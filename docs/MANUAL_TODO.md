# 手動で実施する作業（チェックリスト）

## 1. アプリ起動と基本確認

- [ ] `streamlit run app.py` でアプリを起動する
- [ ] サイドバーから患者を選択し、`算定明細` 画面が表示されることを確認する
- [ ] エラーなく `views/page_detail.py` の新UI（基本情報/判定/麻酔/薬剤/検査/コピー/保存系）が描画されることを確認する

## 2. 基本情報セクション確認

- [ ] 基本情報グリッドに以下が表示されることを確認する  
  `感染症` / `感染症有無` / `麻酔科医` / `術者` / `最初の麻酔開始時間`
- [ ] 手術日が選択患者のデータと一致していることを確認する

## 3. 判定セクション確認

- [ ] ヘッダーの `ライン` 列に `動脈` が含まれる患者で、Aライン判定が `あり` になることを確認する
- [ ] `動脈` が含まれない患者で、Aライン判定が `なし` になることを確認する
- [ ] ナビ判定（対象/非対象/判定不可）が期待どおり表示されることを確認する

## 4. 薬剤セクション（最重要）

- [ ] カテゴリ順が以下固定で表示されることを確認する  
  `麻酔薬` → `術後鎮痛薬` → `注射薬` → `その他薬剤` → `Aライン` → `★項目`
- [ ] 各カテゴリが `st.data_editor(num_rows="dynamic")` で編集可能であることを確認する
- [ ] 行追加・行削除・セル編集ができることを確認する
- [ ] 編集後に `box2` へ反映され、画面再表示後も状態が維持されることを確認する
- [ ] `術後鎮痛薬` の先頭行だけが `/33+` 付き貼り付けコードになることを確認する

## 5. Aライン連動確認

- [ ] Aライン判定が `あり` の患者で、Aライン薬剤が自動で表示されることを確認する
- [ ] Aライン判定が `なし` の患者で、Aライン薬剤が自動追加されないことを確認する
- [ ] `aline_master.csv` の内容変更時に表示へ反映されることを確認する

## 6. コピー機能確認

- [ ] `全コードをコピー` ボタンでクリップボードにコードが入ることを確認する
- [ ] 削除状態の行や `—` の行がコピー文字列に含まれないことを確認する
- [ ] 複数カテゴリのコードが改行区切りでコピーされることを確認する

## 7. 保存・確定・リセット確認

- [ ] `保存` で `edit_history` とステータス更新が行われることを確認する
- [ ] 未保存変更がある状態では `確定` で警告されることを確認する
- [ ] `全てリセット` で編集が初期化されることを確認する
- [ ] 保存後に再読込しても反映内容が一致することを確認する

## 8. 追加の運用作業

- [ ] 本番想定データで最低3患者分の目視確認を行う
- [ ] 必要ならスクリーンショットを取得して引継ぎ資料に添付する
- [ ] 不具合が出た場合は再現手順（患者ID/操作手順/期待値/実際値）を記録する
